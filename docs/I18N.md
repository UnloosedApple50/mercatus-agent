# Internationalization (i18n)

Mercatus Agent supports 15 languages with full UI translation.

## Supported Languages

| Code | Language |
|------|----------|
| en | English |
| pt-BR | Português (Brasil) |
| es | Español |
| fr | Français |
| de | Deutsch |
| it | Italiano |
| ja | 日本語 |
| ko | 한국어 |
| zh-CN | 中文 (简体) |
| ru | Русский |
| ar |العربية (RTL) |
| hi | हिन्दी |
| nl | Nederlands |
| tr | Türkçe |
| pl | Polski |

## RTL Support

Arabic (ar) is rendered right-to-left automatically.

## Implementation

Translations are defined in `src/mercatus/server/static/js/i18n.js`.

### Usage in HTML

```html
<span data-i18n="nav.dashboard">Dashboard</span>
```

### Usage in JavaScript

```javascript
const text = t('nav.dashboard', 'Dashboard');
```

## Adding Translations

1. Add the key to `I18N_STRINGS` in `i18n.js`
2. Provide translations for all 15 languages
3. Use `data-i18n` attribute in HTML

## Language Selection

Language is stored in `localStorage.mercatus_lang` and persists across sessions.
